# TP Integrador – CMFP "Ricardo Rojas"

🌐 **Sitio web estático – Primer proyecto personal**

Este proyecto fue desarrollado como **Trabajo Práctico Integrador** durante mi formación inicial en desarrollo web.  
Es un sitio web estático orientado a un espacio de bienestar / spa ficticio llamado **Espacio Armonía**.

👉 Es mi **primer proyecto**, por lo que el foco estuvo en:
- Aprender la estructura de un sitio web real
- Organizar archivos HTML, CSS y JavaScript
- Integrar estilos, imágenes y scripts externos

---

## 🧩 Tecnologías utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **jQuery**
- **Bootstrap**
- **Font Awesome**

## 🖥️ Descripción general

El sitio cuenta con:

- Página principal con presentación del espacio
- Sección “Nuestro Espacio” con carrusel de imágenes
- Sección de servicios y técnicas
- Página de contacto con mapa embebido y redes sociales
- Diseño responsive
- Navegación entre múltiples páginas HTML

---

## 🎯 Objetivo del proyecto

El objetivo principal fue **aplicar los conocimientos básicos de desarrollo web** y entender cómo se construye un sitio completo desde cero, trabajando con:

- Maquetado HTML
- Estilos CSS
- Organización de recursos
- Interacción básica con JavaScript
